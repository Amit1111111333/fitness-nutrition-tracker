# Fitness & Nutrition Tracker

A simple Android app for tracking daily food consumption and exercise activity.

## Features
- 📊 Daily summary with food consumed, target goal, and calories burned
- 🍎 Log food intake in grams
- 🔥 Log exercise/burn data
- 💾 Data persists permanently
- 📱 Simple and clean UI
- 📈 View history of all entries

## Screens
1. **Home Screen** - Daily overview with totals
2. **Add Food Screen** - Log food consumption
3. **Add Burn Screen** - Log exercise calories burned
4. **History Screen** - View all entries

## Built With
- Java (100% Java, no Kotlin)
- Android Studio
- SQLite Database
- Material Design basics

## How to Run
1. Clone the repository
2. Open in Android Studio
3. Run on emulator or device
